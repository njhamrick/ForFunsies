## Terminal Gremlin

`terminal_gremlin.py` is a ridiculous little terminal program that:

- judges your emotional stability
- challenges you for a secret password
- tracks failed login attempts
- calculates a threat level
- assigns a gremlin clearance level
- produces a completely trustworthy security assessment

### Run it

```bash
python terminal_gremlin.py
